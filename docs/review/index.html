声で数える編み物カウンター — screen recordings for App Review

Recorded on a physical iPad (the app is an iPhone app and runs on iPad in compatibility mode). Audio is included so that the spoken voice commands can be heard.

1. App flow (starts from launching the app on the Home Screen)

Launch from the Home Screen → create a project (set / repeat / row) → count by tapping and −1 → microphone explanation screen → "次へ" (Next) → allow Microphone and Speech Recognition → count by voice ("tsugi" = next, "modoru" = back, "ima doko" = where am I) → add a reminder → add a row memo and hear it read aloud → count history → Settings showing the purchased In-App Purchase → create a second project without the purchase screen.

Download 1_app-flow.mp4

2. In-App Purchase flow

Recorded first, on the same iPad. With one project created (the free limit), tapping "+" opens the purchase screen → purchase "プロジェクト無制限" (non-consumable, TestFlight sandbox) → a second project can be created.
